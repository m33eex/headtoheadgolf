# HeadToHeadGolf Website — Version 1

Static, mobile-friendly promotional website for free GitHub Pages hosting. No paid domain or hosting required.

## Publish with GitHub Pages
1. Create a free GitHub account if needed.
2. Create a new **public** repository named `headtoheadgolf` (or use a repository named `<username>.github.io` for a root website).
3. Upload the **contents of this website folder** to the repository root: `index.html`, `style.css`, the four legal `.html` pages, `.nojekyll`, and `robots.txt`.
4. Open repository **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Once GitHub finishes deployment, the website should be at `https://<username>.github.io/headtoheadgolf/` (or `https://<username>.github.io/` for a username repository).
6. Open every page on a phone and desktop. Ensure legal URLs work publicly without signing in.
